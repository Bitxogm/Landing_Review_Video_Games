Proyecto de Diseño de Web sobre videojuegos , del curso CSS3 deVictor Robles de la plataforma Udemy.
Utilizando metodologia Bem para las clases CSS.
Segun diseño original,todas las secciones de la Web,estaban en un unico archivo Index,al igual que todos los estilos CSS.
En este caso,he separado las secciones de que se compone en archivos independientes HTML , al igual que los estilos, cada archivo CSS corresponde a cada seccion de seccion CSS, para que todo sea un poco mas claro y mas conciso.
Los archivos HTML se corresponden tambien con una archivo JS, en el cual mediante la funcion fetc() hacemos una solicitud para renderizar el archivo en el 
index.html.
La interactividad segun diseño original esta insertada en cada archivo JS al cual corresponde.
